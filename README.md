# Entreno en Casa

Web app instalable (PWA) que arma una rutina diaria para entrenar en casa con peso corporal, bandas elásticas y bicicleta.

- Rutina por día según los días disponibles (configurable), con ejercicios que rotan cada semana y progresión con semana de descarga cada 4.
- Demostración animada de cada ejercicio, con pasos y errores comunes.
- Modo entrenamiento con temporizadores, descansos y aviso sonoro.
- Progreso e historial guardados en el dispositivo.

Abrir: https://matum02-m.github.io/entreno-casa/

Para instalarla: en Android, Chrome → menú ⋮ → *Agregar a la pantalla principal*. En iPhone, Safari → Compartir → *Agregar a inicio*.
